# YouTube Content Filter

YouTube のおすすめに出る、避けたい話題の動画を、端末内の AI（Chrome の Prompt API）の判定で隠す Violentmonkey 用のユーザスクリプトです。

まだ作っている途中で、インストールしても何もしません。

## 開発

開発・実機での確認・リリースの手順は [CONTRIBUTING.md](CONTRIBUTING.md) にあります。
AI の判定の土台は youtube-comment-filter から複製しています（[docs/upstream.md](docs/upstream.md)）。
