# YouTube Content Filter

YouTube のおすすめに出る、避けたい話題の動画を、端末内の AI（Chrome の Prompt API）の判定で隠す Violentmonkey 用のユーザスクリプトです。
気持ちが落ち込んでいるときや、悲惨なニュースの続報を見たくないときのために作りました。

判定は端末の中だけで行います。避けたい話題の一覧や動画のタイトルを、外へ送ることはありません。

## 何をするか

次の場所に出る動画を、タイトルとチャンネル名から判定します。

- ホーム（Shorts の棚を含む）
- 動画ページの右の列・自動再生の次の動画・再生が終わったときの候補
- 検索結果に差し込まれる棚（Shorts の棚など）。検索で出た本来の結果は判定しません

動画の枠は、判定が終わるまで隠します。サムネイルとタイトルが一瞬見えるだけでも困るためです。
判定の結果に応じて、次のように見せます。

| 判定 | 見せ方 |
| --- | --- |
| 当たらない | そのまま見せる |
| 当たる | 枠ごと消す |
| 当たるかもしれない | サムネイルをぼかしてタイトルを伏せ、「〇〇の話題かもしれません」の帯を出す |
| 判定できなかった | サムネイルをぼかしてタイトルを伏せ、「判定できませんでした」の帯を出す |

帯を押すとその場だけ表示し、もう一度押すと戻します。この切り替えは保存しません。

画面の左下に、隠した件数とぼかした件数を出します。
画面で隠しても、YouTube のおすすめの仕組みは変わりません。
件数が多いときは、動画のメニューの「興味なし」を使うと、似た動画が出にくくなります。

判定に迷う動画は、見せる側ではなく隠す側に倒します。
見たいものが隠れるより、見たくないものが見えてしまうほうが困るという考えからです。

## 必要なもの

- デスクトップの Chrome 149 以上（Prompt API は Windows / macOS / Linux / ChromeOS のみ）
- Chrome Web Store 版の Violentmonkey
- Chrome 138 以降では、`chrome://extensions` → Violentmonkey の「詳細」で「ユーザースクリプトを許可」をオンにする
- Prompt API のモデル用の空き容量とハードウェアの要件（<https://developer.chrome.com/docs/ai/get-started> ）を満たしていること

## インストール

Violentmonkey を入れた Chrome で次の URL を開くと、インストール画面が開きます。

<https://github.com/hazymoon/youtube-content-filter/releases/latest/download/youtube-content-filter.user.js>

新しい Release が出ると、Violentmonkey が自動で更新します。

## 設定

### 避けたい話題

Violentmonkey のスクリプトの「値」タブにある `avoidTopics` に、話題を並べた配列で書きます。
値は初回の起動で空の配列として作られます。
空のままなら、このスクリプトは何もしません。

```json
[
  { "name": "災害", "description": "地震・台風・洪水などの災害の被害や、その続報。" },
  { "name": "〇〇事件", "description": "〇〇で起きた事件の報道と、その後の裁判の続報。", "until": "2026-12-31" }
]
```

| 項目 | 書き方 |
| --- | --- |
| `name` | 話題の名前。帯の「〇〇の話題かもしれません」に出る。空にできず、ほかの話題と重ねられない |
| `description` | AI への説明。どんな動画を避けたいかを具体的に書く。関係者の名前や地名を書くと、続報を拾いやすくなる |
| `until` | この日（`YYYY-MM-DD`）まで判定する。省略すると期限なし。期限を過ぎた話題は判定から外す |

書き換えたら、ページを読み込み直すと反映されます。
話題を変えると、それまでの判定の結果は使わずに判定し直します（`until` だけを変えたときは判定し直しません）。

`avoidTopics` の書き方が正しくないときは、すべての動画を「判定できませんでした」の帯でぼかし、理由を DevTools の console に出します。
読めなかったまま空として扱うと、避けたい話題が見えてしまうためです。

### その他の設定

「値」タブに次の名前で値を書くと変えられます。
書いていない値は既定値を使います。
型や範囲が正しくない値は既定値に戻し、理由を DevTools の console に出します。

| 名前 | 型 | 既定値 | 意味 |
| --- | --- | --- | --- |
| `aiEnabled` | 真偽値 | `true` | `false` にすると、このスクリプトは何もしない |
| `aiBatchSize` | 1 以上 10 以下の整数 | `1` | 1 回の AI 呼び出しでまとめて判定する件数。まとめると全体は速くなるが、最初の 1 件が出るまでが遅くなる（docs/spike.md） |
| `aiTimeoutMs` | 1 以上 2147483647 以下の整数 | `30000` | 1 回の判定にかける時間の上限（ミリ秒） |
| `aiMaxChars` | 1 以上の整数 | `500` | AI に渡すタイトルとチャンネル名の、それぞれの最大文字数 |
| `aiCacheMaxEntries` | 1 以上の整数 | `5000` | 判定の結果を保存しておく件数の上限 |
| `debug` | 真偽値 | `false` | 判定の経過を DevTools の console に出すか |

## 限界

- 判定の材料はタイトルとチャンネル名だけです。タイトルに出ていない話題（サムネイルの画像だけで分かるものなど）は拾えません
- Shorts の枠にはチャンネル名が出ないので、タイトルだけで判定します
- AI は誤ります。関係のない動画を消すことも、当たる動画を見逃すこともあります
- 1 件の判定に 1 秒ほどかかるので、開いた直後は動画の枠がしばらく空いて見えます。2 回目からは保存した結果を使うので速くなります
- AI が使えない環境（モデルのダウンロードが要るのに済んでいない、など）では、すべてぼかして見せます。ダウンロードが要るときは、左下の件数バーの「AI を準備する」を押してください
- Shorts の再生画面と、アプリの外のリンクから開いた動画ページは対象外です。どちらも再生がすでに始まっているためです
- YouTube の画面の作りが変わると、隠せなくなることがあります
